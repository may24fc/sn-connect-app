# Finance Redesign Optimization

## Current Status

The 2026-10-07 and 2026-10-12 Finance migrations are applied to local and production Supabase; the 2026-10-13 property-term migration is local only. Properties belongs to Property Development and supports first-of-month historical terms plus monthly expected-rent overrides. Optional budgets stay hidden when unset while spend and subscription monitoring remain visible. The redesign routes use the Control Hub font tokens and one AppShell spacing layer; an automated browser geometry check guards against the prototype's prior nested max-width and padding. Admin, super-admin, and temporary Accounting-role Finance/Properties routes pass local desktop/mobile Playwright, including long, error, and dark states; the temporary Accounting assignment was restored. A valid 30-sample local before/after comparison is recorded below. The control route moved in the same direction, so no general speed claim is made. Real Wise artifacts, populated-record visual review, pending Finance policies, and production deployment of the new migration remain deferred in the [task tracker](task-tracker.md) and [pending decisions](pending-decisions.md).
