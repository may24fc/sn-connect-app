# Work Tracker Task Tracker

## Current Status

The Work Tracker has a department-lead management model: super-admins appoint eligible department leads; projects can add departments through an invitation/acceptance flow; and milestone completion awards XP once using completed-task contribution. The 2026-11-04 source changes add directory-wide department-lead search, multiple project leads, and individual project invitations for assignments outside the assigner's appointed departments. Department leads see department work data without administrator-only Hub activity. See [optimization.md](optimization.md) for the authorization, invitation, and reward-flow records. The narrower Kanban work remains in [../work-tracker-kanban/task-tracker.md](../work-tracker-kanban/task-tracker.md). The two new project migrations were applied and verified locally and in production on 2026-11-04 with explicit approval; application rollout verification remains outstanding.
