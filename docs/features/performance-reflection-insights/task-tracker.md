# Performance Reflection Insights Task Tracker

## Current Status

Performance admins (`admin`, `super_admin`) can open **Ask AI** on the 5% Reflection review (`/admin/performance/monthly-self-evaluations?tab=five-percent`) and ask free-form, follow-up questions about everyone's reflections. Answers stream from OpenAI `gpt-5.4-mini` over the selected month plus up to six earlier months, with every number computed in code first. **Identifiers never reach OpenAI:** teammates are sent as `Person-07`, other people, places, and organizations mentioned in reflections as `Mention-003`, and personal details (links, handles, ID numbers, addresses, birth dates, emails, phones) as placeholders. Tokens are swapped back to names on the server, so admins still see and save answers with real names. Conversations are saved per user and visible only to their owner while they remain a performance admin.

Implemented and verified locally (unit, SQL RLS, mocked Playwright, and real-stack browser runs against local Supabase and OpenAI). Migrations `20261025000001`–`20261025000003` are applied in production (the first through the 2026-10-24 incident, the other two by explicit request). Code delivery (commit and push) is in progress.
