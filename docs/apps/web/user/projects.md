# Projects Workspace

This guide covers employee project planning, execution tracking, and pool workflows.

## Route Map

- /projects — Project dashboard/list
- /projects/new — Create a new project
- /projects/invitations — Review and respond to project invitations
- /projects/[id] — Project detail view
- /projects/pool — Shared project pool and backlog
- /work-tracker — Combined project and task visibility

## Projects (/projects)

The projects page provides:

- Personal and assigned project visibility
- Health/status tracking
- Progress summaries

## Create Project (/projects/new)

Use the create page to define:

- Project name and description
- Scope and target outcomes
- Timing and ownership

Choose one or more project leads. Leads can manage the project and are also contributors;
ordinary contributors can participate without receiving lead management access.
The first selected lead is the proposed primary lead. The creator retains project-management
access even when another person is primary.

People in departments you lead can be added directly. Anyone else receives an in-app
invitation to accept or decline; this also applies to administrators. If the proposed
primary needs an invitation, you remain primary until they accept. The current primary's
department is used for the initial project department. Adding another lead or accepting
an invitation does not automatically add that person's department.

## Project Detail (/projects/[id])

Detail view supports:

- Milestone/progress review
- Status and health visibility
- Collaboration context and updates

Use **Manage Contributors** to add contributors, promote or demote co-leads, and review or
cancel pending invitations. A contributor from outside your led departments keeps their
current membership while a lead invitation is pending; declining does not remove them.
The primary lead cannot be removed or demoted there.

## Project Invitations (/projects/invitations)

Open an invitation from its notification or from the project list. Review the project,
requested role, and inviter, then accept or decline. A pending invitation does not itself
grant access; existing access from another role or membership is unaffected.

If a primary-lead invitation is accepted after someone else has changed the primary lead,
you join as a co-lead instead of replacing that newer primary. If you accept, use **Open
project** to continue. A cancelled, already answered, or unavailable invitation cannot be
accepted again.
The Work Tracker shows tasks linked to each project for context. Linked task completion does not change calculated project progress; milestone checklist completion remains the canonical progress source.

## Project Pool (/projects/pool)

The pool view is for claimable or shared initiatives.

Typical actions:

- Review available backlog items
- Claim work from the pool
- Track pooled project movement
