# Documents (My 201 Files)

The Documents page (`/files`) is where you upload and manage your employment records — collectively known as your **201 file**.

## Route Map

- /files

## Document Overview

At the top of the page you'll see:

- **Progress bar** — Shows what percentage of your required documents have been approved
- **Status legend** — Counts for each status: Approved, Pending Review, Missing, Rejected

## Document Categories

Your 201 file is organized into categories:

| Category | Documents |
|----------|-----------|
| **Identity** | Government-issued ID, Birth Certificate |
| **Clearances** | NBI Clearance |
| **Government** | SSS E1, PhilHealth MDR, Pag-IBIG MID, TIN |
| **Education** | Diploma / Transcript of Records |

## Document Statuses

| Status | Meaning |
|--------|---------|
| **Approved** | HR has reviewed and accepted the document |
| **Pending Review** | Uploaded and waiting for HR review |
| **Not Uploaded** | You still need to upload this document |
| **Rejected** | HR rejected the document — check notes and re-upload |

## Uploading a Document

1. Find the document with status **Not Uploaded** (or **Rejected**)
2. Click the action menu (⋯) → **Upload** (or **Replace**)
3. Drag and drop a file into the upload area, or click to browse your computer
4. Click **Upload** to submit

### File Requirements

| Rule | Value |
|------|-------|
| Maximum file size | 10 MB |
| Accepted formats | PDF, JPG, PNG |

> **Tip:** Scan physical documents as PDF for the best quality. Make sure the entire document is readable.

## Viewing and Downloading

- Click the action menu (⋯) → **View** to preview a document
- Click **Download** to save a copy to your computer

## Re-uploading a Rejected Document

If HR rejects a document, you'll see a **Rejected** status badge. Check the reviewer's notes for the reason (e.g., "image too blurry", "wrong document"), then:

1. Click the action menu → **Replace**
2. Upload the corrected file
3. The status will change back to **Pending Review**

## Searching and Filtering

- Use the **search bar** to find documents by name
- Use the **filter button** for advanced filtering options
