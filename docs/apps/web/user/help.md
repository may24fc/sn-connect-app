# Help Center

The Help Center provides guided walkthroughs for the most common self-service workflows.

## Routes

- `/help`
- `/help/reports`
- `/help/invoices`
- `/help/performance-reviews`

Delegated ATS routes (role-permission dependent):

- `/ats/recruitment`
- `/ats/jobs`
- `/ats/jobs/applications`
- `/ats/jobs/archive`

## How to Use It

1. Open Help Center from the sidebar.
2. Choose a topic based on the workflow you need.
3. Follow step-by-step guidance and FAQ entries.

## Available Guides

- Reports help: report lifecycle, draft vs submit, and associate daily EOD expectations.
- Invoices help: invoice lifecycle, status definitions, and privacy controls.
- Performance reviews help: OKRs/KPIs basics, review-cycle flow, and rating reference.

## When to Use Help vs AI Assistant

- Use Help Center for structured procedural walkthroughs.
- Use AI Assistant for policy questions or follow-up clarifications.
