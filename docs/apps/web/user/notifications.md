# Notifications

The Notifications page (`/notifications`) shows all your system notifications in one place.

## Route Map

- /notifications

## Viewing Notifications

Notifications are displayed as a list, with unread items highlighted. Each notification shows:

- **Type Icon** — Color-coded icon indicating the notification type
- **Title** and message body
- **Timestamp** — Relative time (e.g., "5 minutes ago", "3 days ago")
- **Unread indicator** — Highlighted background for unread notifications

## Notification Types

| Type | Icon | Description |
|------|------|-------------|
| Task Assigned | Clipboard | A new task has been assigned to you |
| Task Due | Target | A task deadline is approaching |
| Report Submitted | File | Your report was submitted successfully |
| Report Approved | Check | Your report has been approved |
| Report Rejected | X | Your report was rejected — review feedback |
| Announcement | Megaphone | A new company announcement was posted |
| New Resource | Folder | A new resource is available in the Information Hub |
| Reminder | Bell | General reminder notification |
| Onboarding Step | Book | An onboarding task requires attention |
| Probation Update | User Check | Your probation status has changed |
| System | Info | System-level notification |

## Filtering

- **Read / Unread** — Toggle to show only unread or all notifications
- **Type Filter** — Filter by notification type (e.g., show only task notifications)

## Actions

### Mark as Read

Click a notification to mark it as read. If the notification has a link, clicking navigates you to the relevant page.

### Bulk Actions

- **Select** individual notifications using checkboxes
- **Mark Read** — Mark all selected notifications as read
- **Delete** — Remove selected notifications permanently
- **Mark All Read** — Mark every notification as read at once

## Pagination

Navigate through your notification history using the Previous / Next pagination controls. The current page position is displayed (e.g., "1–20 of 45").
