# Expenses and Reconciliation

This guide covers employee-side expense submission and the leadership expense desk views.

## Route Map

- /expenses — Personal expense entry and history
- /expenses/desk — Leadership review desk for reconciliation
- /expenses/desk/analytics — Expense analytics and trend dashboards
- /expenses/verify — Matching and verification workflow page

## Expenses (/expenses)

Use this page to:

- Submit expense records
- Track processing status
- Review matched and flagged entries

## Expense Desk (/expenses/desk)

The desk view is used for operational review and decisions:

- Filter by status, department, and date range
- Review exception cases
- Record leadership decisions where applicable

## Analytics (/expenses/desk/analytics)

Analytics includes:

- Period-based trend charts
- Category and status breakdowns
- Department-level spend comparison

## Verify (/expenses/verify)

Verification supports matching and reconciliation checks before final settlement.
