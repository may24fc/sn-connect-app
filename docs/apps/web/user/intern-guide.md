# Intern Guide

This guide covers features specific to interns. Interns share most features with employees but have a specialized dashboard and daily reporting workflow.

## What's Different for Interns

| Feature | Employee | Intern |
|---------|----------|--------|
| Dashboard | Employee dashboard | Intern dashboard with hours tracking |
| Tasks | ✅ | ✅ |
| Profile | ✅ | ✅ |
| 201 Files | ✅ | ✅ |
| Invoices | ✅ | ❌ |
| Weekly Reports | ✅ | ❌ |
| Daily EOD Reports | ❌ | ✅ |
| Performance | ✅ | ✅ |
| Information Hub | ✅ | ✅ |
| AI Assistant | ✅ | ✅ |

## Intern Setup

When you first log in, the system redirects you to the **Intern Setup** page (`/intern/setup`) to collect:

- School and program
- Start and end dates
- Required hours
- Supervisor assignment

Complete this before accessing the rest of the portal.

## Intern Dashboard (`/intern/dashboard`)

Your dashboard is focused on internship progress and daily reporting.

### Profile Card

At the top, a card displays:

- Your name, program, and school
- Department and supervisor
- Status badge (Active)
- Days remaining badge

### Stats Cards

| Card | Description |
|------|-------------|
| **Completed Hours** | Total hours you've logged so far |
| **Required Hours** | Target hours for your internship |
| **Reports Submitted** | Number of EOD reports filed |
| **Days Remaining** | Business days left in your internship |

### Hours Progress

A visual gauge showing:

- Hours logged vs. hours required
- Internship start and end dates
- Percentage complete

### Today's Status Card

Shows whether you've submitted today's EOD report:

- **Green** — Report submitted for today
- **Yellow** — Report pending, with a **"Submit Now"** button
- Internship period timeline progress bar

## Daily EOD Reports

Interns submit an **End-of-Day (EOD) report** every working day instead of weekly reports.

### Submitting a Report

1. From your dashboard, click **"Submit Now"** (or navigate to the report section)
2. Fill in the form:

| Field | Required | Description |
|-------|----------|-------------|
| Tasks Completed | Yes | What you accomplished today |
| Hours Logged | Yes | Number of hours worked |
| Key Learnings | No | What you learned |
| Challenges Faced | No | Any problems or blockers |

3. Click **Submit**

### Recent Reports

Below the submission form, you'll see your recent EOD reports showing:

- Date and status badge
- Hours logged that day
- Preview of tasks completed
- **"View All"** link to full report history

## Supervisor Approval

After you submit a daily report, your supervisor can review and approve it. You'll see the approval status on each report entry.

## Shared Features

Interns have full access to these features — see the respective guides:

- [Tasks](tasks.md) — View and update assigned tasks
- [Documents](documents.md) — Upload 201 files
- [Performance](performance.md) — Track OKRs and KPIs
- [Information Hub](information-hub.md) — Read announcements, browse resources
- [AI Assistant](ai-assistant.md) — Ask HR questions

## Tips for Interns

- **Submit your EOD report daily** — Your dashboard clearly shows whether today's report is pending
- **Log hours accurately** — Hours auto-accumulate toward your required total
- **Upload documents early** — Get your 201 file complete as soon as possible
- **Check announcements** — Stay informed about company events and policies
