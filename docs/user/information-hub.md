# Information Hub

The Information Hub (`/information-hub`) is your central place for company announcements and shared resources.

## Tabs

The page is split into two tabs:

| Tab | Description |
|-----|-------------|
| **Announcements** | Company news, HR updates, events, and notices |
| **Resources** | Documents, links, videos, and other reference materials |

## Announcements

### Browsing Announcements

Filter announcements by category using the buttons at the top:

- **All** — Show everything
- **HR Updates** — Policy changes, benefits info
- **Benefits** — Insurance, perks, allowances
- **Events** — Company events and activities
- **Performance** — Review cycle updates
- **Training** — Learning opportunities

### Reading an Announcement

Each announcement card shows:

- **Category badge** — Color-coded category label
- **"New" badge** — Appears on recent, unread announcements
- **Title** — Announcement headline
- **Preview** — First few lines of content
- **Posted date** — When it was published

Click a card to read the full announcement in a detail dialog.

### Pinned Announcements

Important announcements may be **pinned** to the top of the feed so they remain visible.

### Starring Announcements

Star an announcement to bookmark it for quick access later.

1. Click the **star icon** (☆) on any announcement card
2. The star turns filled (★) to indicate it's saved
3. Click again to remove the star

### Starred Announcements (`/announcements/starred`)

View all your starred announcements in one place:

- Access via the **"Starred"** link in the announcements section or the sidebar
- Announcements are listed in reverse chronological order by when you starred them
- Click any card to read the full announcement
- Remove a star directly from the starred list

## Resources

### Browsing Resources

- Use the **search bar** to find resources by name or description
- Use the **category browser** to filter by type (documents, links, videos, etc.)
- **Featured** resources are highlighted at the top

### Resource Cards

Each resource card displays:

- Resource name and description
- Category and type
- File format or link indicator
- **Bookmark icon** — Click to save the resource for quick access later

### Category Browsing (`/information-hub/resources/category/[category]`)

Click a category to view all resources in that category:

- **Sort** by Newest, Most Viewed, Most Downloaded, or Title
- **Filter** by resource type within the category
- **Search** within the category
- Resources displayed in a responsive 4-column grid

### Resource Detail (`/information-hub/resources/[id]`)

Click any resource to view its full detail page:

- **Video resources** — Embedded video player with signed streaming URL
- **Document resources** — In-browser document viewer with streaming preview
- **Actions** — Bookmark, Download, Mark as Completed
- **Related Resources** — Grid of similar resources
- Views are tracked automatically

### Bookmarks (`/information-hub/resources/bookmarks`)

Access your saved resources:

- Grid of all bookmarked resources
- Personal notes for each bookmark
- Remove bookmark button
- Empty state with a prompt to browse resources

### Downloading / Opening

- For documents: download the file or preview in-browser
- For links: open the external URL
- For videos: stream directly in the player

## My Growth

The **My Growth** section (under the Announcements tab) tracks your personal learning and development:

- **Stats Cards** — Completed courses, in-progress items, learning hours
- **Learning list** — Courses and goals with progress bars, completion badges, and due dates
