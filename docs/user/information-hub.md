# Information Hub

The Information Hub (`/information-hub`) is your central place for company announcements and shared resources.

## Tabs

The page is split into two tabs:

| Tab | Description |
|-----|-------------|
| **Announcements** | Company news, HR updates, events, and notices |
| **Resources** | Documents, links, videos, and other reference materials |

## Announcements

### Browsing Announcements

Filter announcements by category using the buttons at the top:

- **All** — Show everything
- **HR Updates** — Policy changes, benefits info
- **Benefits** — Insurance, perks, allowances
- **Events** — Company events and activities
- **Performance** — Review cycle updates
- **Training** — Learning opportunities

### Reading an Announcement

Each announcement card shows:

- **Category badge** — Color-coded category label
- **"New" badge** — Appears on recent, unread announcements
- **Title** — Announcement headline
- **Preview** — First few lines of content
- **Posted date** — When it was published

Click a card to read the full announcement in a detail dialog.

### Pinned Announcements

Important announcements may be **pinned** to the top of the feed so they remain visible.

## Resources

### Browsing Resources

- Use the **search bar** to find resources by name or description
- Use the **category browser** to filter by type (documents, links, videos, etc.)
- **Featured** resources are highlighted at the top

### Resource Cards

Each resource card displays:

- Resource name and description
- Category and type
- File format or link indicator
- **Bookmark icon** — Click to save the resource for quick access later

### Downloading / Opening

- Click a resource card to view details
- For documents: download the file
- For links: open the external URL

## My Growth

The **My Growth** section (under the Announcements tab) tracks your personal learning and development:

- **Stats Cards** — Completed courses, in-progress items, learning hours
- **Learning list** — Courses and goals with progress bars, completion badges, and due dates
