# Dashboard

Your dashboard is the first page you see after logging in. It provides a personalized overview of your HR status and quick access to common actions.

## Employee Dashboard (`/dashboard`)

### Welcome Header

A time-based greeting (Good morning / afternoon / evening) with your name and a **"View My Files"** shortcut button.

### Stats Row

Four summary cards at the top:

| Card | What It Shows |
|------|---------------|
| **Onboarding Progress** | Percentage of onboarding tasks completed, with trend arrow |
| **Probation Stage** | Current probation stage (1–4) and days remaining |
| **Tasks Due** | Number of pending tasks assigned to you |
| **Notifications** | Count of unread notifications |

### Quick Actions

A grid of shortcut buttons:

- **Upload Files** — Jump to your 201 files page
- **Submit Report** — Start a new weekly report
- **View Calendar** — Open the calendar (coming soon)

### Onboarding Progress Card

- Visual progress bar with percentage
- Task completion count (e.g., "3 tasks remaining")
- On Track / At Risk status badge
- Link to view full onboarding checklist

### Upcoming Events

- List of scheduled events (performance reviews, team building, training)
- Date and time for each event
- **"View All"** link to the calendar

### Latest Announcements

- Recent company announcements with category badges
- Timestamps
- **"View All"** link to the Information Hub

## Intern Dashboard (`/intern/dashboard`)

Interns have a specialized dashboard focused on hours tracking and daily reports. See the [Intern Guide](intern-guide.md) for details.
