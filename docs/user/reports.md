# Weekly Reports

The Reports page (`/reports`) lets you submit weekly activity reports and track your submission history.

> **Note:** This feature is available to employees only. Interns use Daily EOD Reports instead — see the [Intern Guide](intern-guide.md).

## Report Overview

At the top of the page you'll see four KPI cards:

| Card | Description |
|------|-------------|
| **Total Reports** | Lifetime report count |
| **This Month** | Reports submitted this month |
| **Pending Drafts** | Drafts you haven't submitted yet |
| **Completion Rate** | Your submission consistency percentage |

Below the KPIs is an **Insights Summary** with:

- Submission streak
- Engagement metrics
- Trend analysis
- Recommendations for improvement

## Creating a New Report

1. Click the **"New Report"** button in the page header
2. Fill in the form at `/reports/new`:

| Field | Required | Description |
|-------|----------|-------------|
| Report type | Yes | Select the type of report |
| Week period | Yes | Pick the week you're reporting on |
| Summary | Yes | Brief overview of the week |
| Accomplishments | Yes | List what you achieved |
| Challenges | No | Any blockers or difficulties |
| Next week plans | No | What you plan to work on |
| Expenditure | No | Amount spent (PHP) |
| Results | No | Revenue or results achieved (PHP) |
| Attachments | No | Supporting files |

3. Choose one of two actions:
   - **Save as Draft** — Save without submitting (you can edit later)
   - **Submit** — Send to your manager for review

## Report Statuses

| Status | Meaning |
|--------|---------|
| **Draft** | Saved but not submitted — editable |
| **Submitted** | Sent for review — no further edits |
| **Reviewed** | Manager has reviewed and provided feedback |

## Viewing Reports

- Click any report in the list to see the full detail view (`/reports/[id]`)
- The detail view shows:
  - **KPI Summary Cards** — Key metrics (total spend, results, ROI)
  - **Summary Card** — Employee, department, and submission date
  - **Insights** — Accomplishments and challenges parsed from report notes
  - **Metrics Table** — Sortable breakdown of all report line items
  - **Next Steps** section
  - **Submit** button — Submit a draft report directly from the detail view

## Filtering Reports

- **Search** — Find reports by name or content
- **Status filter** — Show All, Draft, Submitted, or Reviewed reports
